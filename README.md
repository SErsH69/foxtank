# ФоксТанк — концепт лендинга

Одностраничный концепт по макету Figma «Фокс танк». Тёмная тема, оранжевый акцент,
анимации появления блоков и «едущая» машина на первом экране.

## Структура
- **index.html** — вся страница (HTML + CSS + JS в одном файле, без сборки).
- **img/** — сюда кладутся фото из макета (см. `img/КАРТИНКИ_СЮДА.md`).
- **serve.js** — крошечный локальный сервер для предпросмотра.

## Запуск локально
```bash
node serve.js
# открыть http://localhost:4173
```
Либо просто открыть `index.html` в браузере (анимации работают и так).
