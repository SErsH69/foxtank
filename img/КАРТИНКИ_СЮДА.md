# Куда класть картинки из Figma

Экспортируй из макета изображения и положи их в эту папку **ровно с такими именами**.
Как только файл появится — он сам подставится на страницу (пока файла нет, показывается
временная векторная иллюстрация, страница не ломается).

## Как экспортировать в Figma
Выдели нужный слой/картинку → правая панель **Export** → формат **PNG**, масштаб **2x** → **Export**.
Для фонового фото героя лучше **JPG** (меньше вес).

## Список файлов

| Имя файла             | Что это (из макета)                                   | Формат |
|-----------------------|-------------------------------------------------------|--------|
| `hero.jpg`            | Фон первого экрана — фура на трассе                    | JPG    |
| `hero-card.png`       | Мини-карточка справа в герое (серебристая цистерна)    | PNG    |
| `polupricepy.png`     | Карточка «Полуприцепы»                                 | PNG    |
| `pricepy.png`         | Карточка «Прицепы» (красная цистерна ОГНЕОПАСНО)       | PNG    |
| `avtocisterny.png`    | Карточка «Автоцистерны»                                | PNG    |
| `cementovozy.png`     | Карточка «Цементовозы»                                 | PNG    |
| `konteynerovozy.png`  | Карточка «Контейнеровозы»                              | PNG    |
| `shtorny.png`         | Карточка «Полуприцеп грузовой шторный»                 | PNG    |

Рекомендуемый размер карточек — ширина ~1000px. Фон героя — ~2400px по ширине.
Фото товаров лучше на прозрачном фоне (PNG) — тогда идеально лягут на тёмные карточки.
